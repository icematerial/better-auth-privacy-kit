# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - 2026-09-22

### Added

- Authenticated privacy data export with secret stripping.
- Consent/withdrawal history model and endpoints.
- Account anonymization with session revocation and account unlinking.
- Optional hard-delete endpoint, disabled by default.
- Application-specific export and anonymization hooks.
- Better Auth client plugin for endpoint inference.
- English and Japanese documentation.
